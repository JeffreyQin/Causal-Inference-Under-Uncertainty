GPT-5.2 PROCESSING SCRIPTS AND GRAPH CONFIGURATIONS
==================================================

Naming convention
-----------------
The six analysis scripts use: <usage>_gpt52_<metric>.py

1. plot_gpt52_heatmap_nll.py
   Usage: calculate and plot NLL sweep heatmaps.

2. plot_gpt52_profiles_nll.py
   Usage: calculate and plot marginal NLL profiles.

3. select_gpt52_best_models_nll.py
   Usage: select the best model for each GPT-5.2 run using NLL.

4. select_gpt52_best_models_aic.py
   Usage: select the best model for each GPT-5.2 run using AIC.

5. plot_gpt52_heatmap_aic.py
   Usage: calculate and plot the two-dimensional AIC sweep heatmap.

6. plot_gpt52_profiles_aic.py
   Usage: calculate and plot marginal AIC profiles.

The separate summarise_gpt52_runs.py script prepares GPT-5.2 JSON logs as
experiments_gpt5.2.csv. It is data preparation, not an NLL/AIC analysis.

AIC definition and model regions
--------------------------------
AIC = 2*NLL + 2*k

SoC-Lesioned region: theta=(19,1), p_gen=0.1; k=0
SoC-Rel region:      theta!=(19,1), p_gen=0.1; k=1
SoC-Gen region:      theta=(19,1), p_gen>0.1; k=1
SoC-Full region:     theta!=(19,1), p_gen>0.1; k=2
